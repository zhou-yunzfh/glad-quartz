# glad-quartz

Senior Software Engineer @ Huawei Canada

处理日常小任务的工具

## 用法

```bash
cat data.txt | go run main.go
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/glad-quartz.git
cd glad-quartz
go build ./...
```
